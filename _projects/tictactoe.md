A Python and Pygame Tic Tac Toe game and my first GitHub project while learning Python and game development.

### Key features

- Player vs Player mode
- Player vs AI mode
- Minimax-based AI
- Animations, score tracking, and sound effects

### Run locally

Install Python, Pygame, and NumPy, then run the main game file. This is a desktop Python game, so a browser-playable demo is not available yet.
