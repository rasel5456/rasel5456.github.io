Winter Is Coming is a complete CSE211L course project that models a fictional Westeros winter relief network. It implements a high-speed registry, deterministic holdfast claims, weighted shortest paths, bounded supply packing, and a minimum-spanning beacon network.

### Key features

- Hand-written binary search and merge sort
- Greedy Shelter War assignment with deterministic tie-breaking
- Heap-based Dijkstra shortest paths over the Kingsroad
- Bounded 0/1 knapsack dynamic programming for family bags and House wagons
- Kruskal minimum spanning tree with union-find
- Folium war and beacon-network maps
- Google Colab/Jupyter-compatible notebook and PDF/DOCX report

### Validated results

- 5,000 households, 21 holdfasts, 3,757 beds, and 45 road segments
- HF-07 route: `HF-07 → HF-06 → HF-03 → WF`, 90.0 road leagues
- Beacon MST: 27 edges and 621.0 leagues
