A deployable e-commerce project using React, Vite, and Supabase. It includes authentication, product data, cart functionality, and order placement backed by PostgreSQL.

### Highlights

- React and Vite frontend
- Supabase authentication and database
- Product browsing and selling flow
- Cart and order placement
- PostgreSQL-backed data with security rules

A public live demo will be added here after deployment and environment variables are configured.
