# About

I am **MD. Rasel Hossen Sawpon**, a Computer Science and Engineering student at **Independent University, Bangladesh (IUB)**. My current interests include web development, cybersecurity, secure software development, and applied Machine Learning.

I use academic and personal projects to strengthen programming, problem-solving, and software engineering skills. My public work currently includes browser-based Android static analysis, React and Vite applications, and a typed Next.js e-commerce interface.

## Areas of focus

- Web development with JavaScript, React, Next.js, TypeScript, and Vite
- Defensive cybersecurity and authorized Android APK static analysis
- Secure software development and practical data handling
- Applied Machine Learning and future research in intelligent, secure systems
